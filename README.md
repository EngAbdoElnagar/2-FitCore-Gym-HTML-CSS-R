# FitCore Gym Layout  

A simple web layout project built using **HTML and CSS**, focusing on using the CSS **`float`** property for structure and alignment.

## 🧠 Idea  
The goal of this project is to design a basic gym-themed webpage and arrange its sections using the classic **float** layout technique — before the era of Flexbox and Grid.

## 🛠 Tools Used  
- HTML  
- CSS (Float Layout)

## 💡 What I Learned  
- How to align elements side by side using `float`.  
- The challenges of managing element flow and clearing floats.  
- How modern methods like Flexbox simplify what float used to handle.
